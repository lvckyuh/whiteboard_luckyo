# Real-Time Shared Whiteboard

A collaborative web-based whiteboard that synchronizes drawings in real-time across multiple users and devices using Firebase Realtime Database.

> **Note:** Dedicated for my love *"Yagiz O."*.

---

## Features

- **Real-Time Collaboration:** Every stroke is saved and synced instantly to anyone viewing the page.
- **Drawing Tools:**
- **Marker:** Custom stroke size and color selection.
- **Color Palette:** Preset swatches + native color picker for custom hex colors.
- **Eraser:** Adjustable eraser tool with dynamic size scaling.
- **Undo / Redo History:** Full history stack supporting up to 50 actions via UI buttons or keyboard shortcuts. (ctrl+z) / (ctrl+shift+z)
- **Responsive & Touch Friendly:** Supports both mouse pointer events and mobile touch gestures with high-DPI canvas scaling.
- **Zero Build Tools:** Powered by HTML5 Canvas and Firebase Web SDK via CDN modules.
